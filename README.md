# Moje Računalo (Python)

Preprosto konzolno računalo, izdelano za demonstracijo uporabe sistema Git
in platforme GitHub.

## Funkcionalnosti
- Sestevanje, odstevanje, mnozenje in deljenje
- Preverjanje deljenja z niclo
- Potenciranje stevil

## Namestitev in zagon
1. Klonirajte repozitorij:
   git clone git@github.com:tianselic/moje-racunalo.git
2. Premaknite se v mapo projekta:
   cd moje-racunalo
3. Zazenite program:
   python racunalo.py

## Zagon avtomatskih testov
python -m unittest test_racunalo.py
